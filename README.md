# iptv-m3u

台灣電視頻道播放清單（IPTV），精選「可播 + 電視盒相容」的頻道。

## 檔案說明

| 檔案 | 內容 |
|------|------|
| `Taiwan_電視盒可播.m3u` | 主清單：**已實測可播**、且**一般 Android 電視盒可播放**的台灣頻道（HLS / http 串流，不含 rtmp）。用影視倉等 App 直接匯入即可。 |

> ⚠️ 本清單為非官方 IPTV 來源，頻道會隨時間失效。若發現某些台播不出，請重新產生清單（見下方「更新方式」）。

## 電視盒匯入步驟（以 Hako Mini + 影視倉為例）

一般 Android 電視盒（Tivimate / Kodi / 內建播放器）**不支援 `rtmp://` 協定**，只吃 HLS（`.m3u8` / `.ctv`）。本清單已經過濾，可直接用。

1. 把 `Taiwan_電視盒可播.m3u` 複製到 **USB 隨身碟**（根目錄即可）。
2. 隨身碟插進電視盒的 USB 口。
3. 打開**影視倉** App → 設定 / 直播配置 / 匯入 → 選**本地檔案** → 點 `Taiwan_電視盒可播.m3u`。
4. 匯入完成後，直播列表就會出現頻道。

> 若影視倉讀不到隨身碟的檔案，試把 `.m3u` 放到盒子的 `Download/` 或 `Movies/` 資料夾。

## 更新方式

清單由本地腳本自動產生（檢查每個頻道是否存活、過濾 rtmp、去重）：

- 腳本：`update_iptv.py` / `update_iptv.bat`（在 Hermes 工作目錄 `hermes 資料夾`）
- 來源命名規則：`~/Downloads/Taiwan-<MMDD>.m3u`（MMDD = 製作當天日期，例如 0820）
- 執行後會：讀來源 → 過濾 rtmp → ffmpeg 探測存活 → 產出 `Taiwan_電視盒可播.m3u` → 上傳 GitHub
- 上傳前會自動清理 repo 內非預期檔案，保持 repo 只含 `README.md` 與本清單
